# Nesine API Timeout Fix — Plan

## Problem
MLScheduler (`trainingScheduler.ts:303`) poll-matches writer'ı 8sn timeout ile çağırıyor. Nesine API bazen 8-10sn sürdüğü için timeout patlıyor, log'lar doluyor, prediction_records boş kalıyor.

## Fix
Tek satır: `trainingScheduler.ts:303` → `AbortSignal.timeout(8_000)` → `20_000`

```typescript
// DEĞİŞİM ÖNCESİ (line 303):
signal: AbortSignal.timeout(8_000),

// DEĞİŞİM SONRASI:
signal: AbortSignal.timeout(20_000),
```

## Etkilenen dosya
- `src/lib/ml/trainingScheduler.ts` (1 satır)

## Doğrulama
1. Deploy sonrası container log'larında `[MLScheduler] poll-matches writer failed` hatası durdu mu kontrol
2. `/api/matches` sayfası canlı maç verisi gösteriyor mu kontrol
