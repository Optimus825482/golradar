# Karpathy Agent Orchestration — The Complete Playbook

Andrej Karpathy, former Tesla AI director and OpenAI co-founder, runs his daily AI workflow with one principle: **20% human / 80% AI agents**, and the ratio keeps shifting. This bundle distills his playbook so any agent can mount it and apply it.

## Themes at a glance

* **20/80 human/AI — the new productivity metric is *tokens you command*, not lines typed.** The human role is orchestration: define objectives, review outputs, steer agents.
* **Skill Issue, not model issue.** When agents fail, the problem is your setup (bad prompt, missing context, unclear constraints), not the model.
* **Parallel Agent Workflow — the Peter Steinberg method:** 4 agents running simultaneously (Feature / Research / Architecture / Review), tiled terminal windows, 20-minute task rotation.
* **AutoResearch — autonomous overnight loops:** objective + metric + CAN-change boundaries + CANNOT-change boundaries. Hit go, review in the morning.
* **program.md / CLAUDE.md = meta-layer that can itself be optimized by another agent.** Instruction optimization is the new hyperparameter tuning.
* **Jaggedness — capability is spiky, not smooth.** Models are brilliant at verifiable tasks (code, math, structured data) and mediocre at non-verifiable (humor, nuance, culture).
* **Jevons Paradox — cheaper software means more engineers needed, not fewer.** The role shifts from writing code to orchestrating systems that write code.
